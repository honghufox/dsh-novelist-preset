# 大纲（Outline）

目标：把一层层抽象落到可直接写正文的章节序列，并确保每章都推进冲突。

## 一句话前提（Logline）
`[主角] 在 [世界/处境] 下，为了 [目标] 对抗 [核心冲突]，代价是 [代价]。`
- 一句话能说清：谁、想要什么、障碍是什么、赌注是什么。
- 写不出一句话前提，说明核心冲突还没立住，先补再往下。

## 三幕/结构（参考雪花法，逐层细化）
1. **第一幕（开端）**：引入主角的日常与渴望 → 触发事件（Inciting Incident）打破平衡 → 主角做出不可逆承诺。
2. **第二幕（发展）**：主角为达目标不断行动并碰壁 → 升级/反转，冲突抬升 → 中段揭示或转折（Midpoint）。
3. **第三幕（高潮与结局）**：最终对决 → 代价兑现 → 新平衡（结局），并给读者情感回报。

## 进阶结构（可选用）
- 长卷可拆成「卷/部」结构，每卷有自己的小高潮与「换地图/换目标」。
- 场景层面：每一场景问「冲突是什么、谁赢谁输、改变了什么」。

## 章节要点
- 每章写 1–3 行要点即可（不是正文），写清：视角人物、本章冲突、章末钩子/转折。
- 用 `chapters/第NNN章-标题.md` 一个文件一章，标题自 chapter 要点取材。

## 校验清单
- [ ] 一句话前提清晰且有赌注
- [ ] 三幕各自的转折点明确
- [ ] 每章要点能推进冲突（不是日常流水）
- [ ] 主线、支线、人物动机彼此咬合
- [ ] 伏笔机会已标出（见 continuity-check）

## 输出
- 写入 `outline.md`（一句话前提 + 三幕 + 章节要点表），必要时分卷文件。
- 交付时给作者一张「章节要点一览表」便于审阅。
